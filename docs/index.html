      02 / UNDER THE HOOD

      From spoken word to alert.

      01

      Stream

      The client sends 16 kHz PCM audio over a WebSocket in one-second chunks. A rolling buffer keeps the last 30 seconds in memory.

      02

      Transcribe

      Deepgram nova-2 returns interim and final segments live, with diarization. Local Whisper is the offline alternative behind one adapter.

      03

      Assess

      Each final segment goes to Gemini at temperature 0.1 for a JSON risk score. Keyword matching takes over when Gemini is unavailable.

      04

      Alert

      Medium scores send a risk_warning. Scores at or above the 0.5 threshold send crisis_detected and lock the session.

      03 / ENGINEERING NOTES

      The details that changed the design.

      Segments are scored alone.

      Each segment is assessed without the ones before it. In fallback mode a single explicit mention scores 0.40, so context across turns is the next change.

      Fallbacks should say so.

      When Gemini fails or returns unparseable JSON, keyword matching answers instead, and the response looks the same. Results need to state which path produced them.

      A lock can silence the transcript.

      Locking on crisis closes the stream, ending transcription when the therapist most needs it. Alerting without stopping capture is the safer design.

      Two speech providers

      Deepgram live streaming or local Whisper, switched by one setting.

      Scores reproduced

      Every demo score was computed with the project's fallback scorer.

      Docker Compose ready

      API container with a health check. Gemini mode is not shown here.

      Current limitations: Therapist Copilot is a portfolio project, not a clinical tool, and its scores are not validated. There are no automated tests yet, token authentication is configured but not enforced, and the Gemini and fallback paths use slightly different score bands. All transcripts on this page are fictional.
